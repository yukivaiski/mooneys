# Mooney Image Generator — Architecture & Workflow Documentation

>[!Note]
> This explanation was generated by Gemini.

## Overview
This application is a desktop GUI built with **PyQt5** and **OpenCV** that converts standard photographs into **Mooney images** (two-tone, high-contrast black-and-white stimuli commonly used in visual perception and neuroscience research). It supports **batch processing** across multiple files and directories without freezing the user interface.

---

## 1. Core Image Processing (`generate_mooney`)
The `generate_mooney` function handles the mathematical transformation of a single image into a binary Mooney stimulus:

1. **Grayscale Conversion:** Loads the input image in single-channel grayscale (`cv2.IMREAD_GRAYSCALE`).
2. **Gaussian Smoothing:** Applies a Gaussian blur (`cv2.GaussianBlur`) to remove high-frequency fine details and noise. The kernel size (`ksize`) is forced to be an odd positive integer as required by OpenCV.
3. **Percentile-Based Thresholding:** 
   * Instead of using a fixed brightness cutoff (like `127`), it calculates a dynamic threshold using `np.percentile` based on the desired `white_pixel_ratio`.
   * For example, a ratio of `0.45` finds the 55th percentile brightness value, ensuring roughly 45% of the output pixels become pure white (`255`) and 55% become pure black (`0`).
4. **Binary Binarization & Export:** Applies `cv2.threshold` (`THRESH_BINARY`) and saves the result to the output directory with `_mooney` appended to the original filename.

---

## 2. Batch Processing & Multithreading (`ProcessingWorker`)
To prevent the GUI from becoming unresponsive during large batch jobs, file discovery and image processing run on a background `QThread`:

* **Input Aggregation:** Iterates through all items in the input list. If an entry is a directory, it scans for `.jpg`, `.jpeg`, `.png`, `.bmp`, and `.webp` files (case-insensitive) using `glob`.
* **Deduplication:** Converts the collected file paths into a `set` so overlapping selections aren't processed twice.
* **Sequential Execution & Signals:** Loops through the deduplicated file list, calling `generate_mooney` on each image and emitting PyQt signals (`progress`, `log_message`, and `finished`) back to the main UI thread.

---

## 3. Graphical User Interface (`MooneyApp`)
The `QMainWindow` class provides a dark-themed (Catppuccin-inspired) interface divided into three workflow sections:

| Section | UI Controls | Function |
| :--- | :--- | :--- |
| **1. Input Files / Directories** | `QListWidget`, Add Images, Add Folder, Remove Selected, Clear All | Allows multi-file selection (`ExtendedSelection`) and folder queueing for batch runs. |
| **2. Parameters** | **Blur Strength** Slider (`1–99`), **White Pixel Ratio** Slider (`0.00–1.00`) | Controls smoothing intensity and the foreground/background luminance split. |
| **3. Output Destination** | `QLineEdit` (default: `mooneys`), Browse Button | Sets or creates the target folder where processed `_mooney` images are saved. |

### Execution Lifecycle
1. Clicking **Generate Mooney Images** validates that inputs and an output path exist, disables the generate button to prevent duplicate runs, and starts `ProcessingWorker`.
2. As each image finishes, `update_progress` updates the `QProgressBar` percentage while `statusBar()` displays real-time file logs.
3. Once `finished` fires, the button re-enables and a `QMessageBox` confirms batch completion.
